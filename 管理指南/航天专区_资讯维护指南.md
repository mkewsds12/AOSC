# 航天开源社区专区 · 资讯维护指南

> 适用后台：GitLink 特色专区「航天开源社区」管理后台
> 维护对象：资讯管理（资讯配置 / 栏目管理 / 资讯列表）
> 整理时间：2026-08-10

---

## 一、后台入口与整体结构

1. 登录 GitLink 账号（需专区管理员权限）
2. 进入特色专区 → 航天开源社区（/zone/space）
3. 页面右上角进入**管理后台**，左侧导航：
   - 资讯管理（重点维护）
     - 资讯配置：专区整体资讯相关设置
     - 栏目管理：先建栏目，再往里发资讯
     - 资讯列表：管理已发布/草稿资讯
   - 项目管理：专区"开源项目"板块的项目维护
   - 会员管理：专区会员
   - 资源管理：专区"资源发布"板块
   - 帮助中心

> 维护顺序建议：**先配置栏目 → 再发布资讯**。

## 二、栏目管理（怎么划分栏目）

### 2.1 推荐栏目划分

前期建议建 **5 个核心栏目**（避免过多难维护），后续可按需增加：

| 序号 | 栏目名称 | 定位 | 示例资讯标题 |
|------|---------|------|-------------|
| 1 | 新闻动态 | 搬运国内外航天/开源行业最新动态（须注明来源） | 长征十号乙首飞成功，我国首次实现火箭海上网系回收 |
| 2 | 社区动态 | 社区公告、上线信息、里程碑事件 | 航天开源社区专区正式上线 |
| 3 | 技术分享 | 星上计算、星上 AI、测运控等技术盘点 | 星上 AI 开源生态盘点：OPS-SAT 与 PhiSat-2 |
| 4 | 知识科普 | 面向大众的航天/开源知识科普 | 卫星姿态是怎么控制的？ |
| 5 | 通知公告 | 竞赛、研讨会、项目征集 | 开源卫星设计征集活动开启 |
| 6 | 项目速递（可选） | 新收录/精选开源项目介绍 | 中国首颗开源立方星 KS-1Q 全套资料收录 |

> 注：栏目以 GitLink 后台实际为准（当前导航：全部 / 新闻动态 / 社区动态 / 技术分享 / 知识科普 / 通知公告），项目速递如后台已取消可并入社区动态。

可选（有内容再开）：**开源故事**（团队/人物访谈）、**政策资讯**（航天政策与开源合规）。

### 2.2 栏目命名建议

- 名称简短（4-6 字），便于列表页展示
- 与专区定位一致：围绕"小卫星 / 立方星 / 智能星 / 星上计算 / 星上智能体 / 测运控"
- "新闻动态"栏目用于**搬运**外部新闻（见 3.4 新闻搬运模板与 5.4 注意事项），保持专区信息活跃
- 栏目一旦发布资讯后不要轻易改名/删除（资讯会跟着栏目走）

### 2.3 栏目首图

- 后台"栏目管理"支持为每个栏目设置首图
- 建议：每个栏目配一张代表性图（banner 风格），尺寸参考 16:9（如 750×420 或 800×450），以平台实际预览为准
- 没有现成图可先不设，用默认占位即可

## 三、资讯列表（怎么填一条资讯）

### 3.1 新增资讯字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 一句话说明主题，有信息量（见草稿示例） |
| 概览 | 是 | 1-2 句摘要，列表页展示，用于快速了解 |
| 标签 | 否 | 1-3 个关键词（如 商业航天/可回收火箭/发射任务），前台以标签块展示 |
| 作者 | 是 | 发布账号（前台展示头像与昵称） |
| 正文 | 是 | 资讯主体，建议"一段文字 + 可选图片"（见 3.3） |
| 首图 | 否 | 资讯封面图；没有可不放 |
| 所处栏目 | 是 | 选择所属栏目（先建栏目） |
| 来源 / 原文链接 | 搬运必填 | 注明来源媒体/机构 + 原文 URL（详情页底部展示） |
| 状态 | 是 | 草稿（编辑中）/ 已发布（对外可见） |
| 首页推荐 | 否 | 勾选后显示在专区首页"新闻动态"区 |

### 3.2 首图规格建议

- 建议比例：16:9（横图）
- 建议宽度：750-800px 左右（与页面展示区匹配，以实际预览为准）
- 格式：JPG/PNG，文件尽量小（<1MB）
- 来源：项目官网图、卫星渲染图、活动海报；外部图片需注意版权

### 3.3 正文模板（"一段文字 + 一张图"风格）

```
第一段（背景/由头）：一句话交代"是什么/发生了什么"。
第二段（主体内容）：介绍项目/活动/技术的要点（2-4 句）。
第三段（价值/号召）：说明对社区/开发者的意义，引导访问或参与。

[可选配一张图：项目 Logo / 卫星图 / 活动海报]
```

要点：
- 正文保持 3 段以内、100-200 字即可，避免长篇
- 配图不是必须，无图可整篇纯文字
- 如需加链接（项目地址等），写在文字里

### 3.4 新闻搬运模板（"新闻动态"栏目专用）

```
标题：直接用新闻原标题或精简改写（保留时间/主体/事件三要素）
概览：一句话概括 + 注明来源媒体/机构
正文：
  一句话交代事件（谁、何时、做了什么）。
  1-2 句补充要点（规模/数据/意义）。
  注明来源出处（媒体名 + 原文链接）。
首图：可放新闻相关配图（卫星图/发布会图），无图可省略
```

示例格式（供套用）：

```
标题：某商业航天公司"XX 星座"首批卫星成功发射
概览：某公司于 8 月 X 日将 XX 星座首批 18 颗卫星送入轨道（来源：XX 航天新闻）。
正文：某商业航天公司于 8 月 X 日成功发射 XX 星座首批 18 颗卫星，星座建成后将提供……服务。
此次发射是该公司今年的第 X 次任务，后续还将分批组网。
（来源：XX 航天新闻 https://xxx）
```

## 五、日常维护规范

### 5.1 发布流程

1. 先建好栏目（见第二节），再新增资讯
2. 新增资讯 → 填标题/概览/正文/首图 → 选栏目
3. 状态选"草稿"先保存检查，确认无误后改为"已发布"
4. 重要资讯勾选"首页推荐"

### 5.2 首页推荐策略

- 首页"新闻动态"区只展示少量推荐资讯，建议**同时只推荐 2-3 条**最新且重要的
- 有新推荐时，先"取消推荐"过期的旧条
- 推荐对象优先：专区上线公告、重大收录、活动通知

### 5.3 排序与维护

- 同栏目内可用"排序"调整顺序
- 每条资讯记录操作者与更新时间，建议固定 1-2 人专职维护，保证口径一致
- 更新频率：至少每月 1-2 条，保持专区活跃

### 5.4 内容红线

- 引用外部项目/图片注意版权与来源标注
- 涉密/未公开的航天内容不放
- 商业宣传内容节制，以开源生态共建为主

### 5.5 新闻搬运注意事项（"行业新闻"栏目）

- **必须注明来源**：媒体/机构名 + 原文链接，不原样大段转载，只做摘要转述（1-2 句要点）
- 优先搬运与专区定位相关的内容：小卫星/立方星发射、开源航天项目动态、星上计算/AI、测运控、开源社区活动
- 控制频率：行业新闻每周 1-2 条即可，避免刷屏；重大事件当天发
- 保持时效：只发 1 周内的新闻；过时新闻及时删除或取消推荐
- 只选可信来源：官方机构（NASA/ESA/商业航天公司官网）、权威航天媒体，不转未经证实的小道消息

## 六、资讯配置与常见问题

### 6.1 资讯配置

- 后台"资讯管理 → 资讯配置"中一般包含专区资讯相关的全局设置（如是否开启评论、默认栏目等），按平台选项勾选即可
- 若页面中有"是否启用资讯/展示条数"类开关，建议启用并将首页展示条数设为 2-3 条

### 6.2 常见问题

| 问题 | 处理 |
|------|------|
| 找不到"新增"按钮 | 确认拥有管理员权限，且在"栏目管理/资讯列表"页右上角 |
| 资讯发出去首页不显示 | 检查是否"已发布"且勾选了"首页推荐" |
| 栏目删除不了 | 栏目下已有资讯时通常不允许删除，先清空或删除该栏目资讯 |
| 首页图片不显示 | 检查首图格式/尺寸是否符合要求，图片链接是否有效 |
| 想让资讯被更多人看到 | 首页推荐 + 发布到对应栏目 + 论坛（forum.gitlink.org.cn）同步转发 |
