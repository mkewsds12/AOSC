# 航天专区 · 资源发布指南

> 适用后台：GitLink 特色专区「航天开源社区」管理后台 → 资源管理
> 维护对象：资源配置 / 资源类别 / 资源领域 / 资源列表
> 整理时间：2026-08-10
> 关联文档：《航天专区_资讯维护指南.md》《航天专区_开源项目管理指南.md》《开源项目调研.md》

---

## 一、后台入口与整体结构

1. 登录 GitLink 账号（专区管理员权限）
2. 进入特色专区 → 航天开源社区 → 管理后台 → **资源管理**
   - 资源配置：资源板块全局设置
   - 资源类别：按**文件格式**分类（系统已内置 9 类，上传自动归类）
   - 资源领域：按**内容**分类（自定义"专栏"，前台左侧筛选）
   - 资源列表：管理已上传的资源
3. 前台对应页面：/zone/space/source
   - 左侧筛选：资源领域（全部 + 各领域）+ 资源类别（全部 + 各文件类型）
   - 右侧：资源卡片列表

> 维护顺序：**先定资源领域（内容专栏）→ 再上传资源**；资源类别系统已配好，基本不用改。

## 二、资源类别（按文件格式，系统内置）

系统已内置 9 个文件类别，上传时按扩展名**自动归类**，一般无需修改：

| 序号 | 类别名称 | 覆盖文件类型 |
|------|---------|-------------|
| 1 | 压缩文件 | zip, rar, 7z, tar, gz, bz2, iso |
| 2 | 文档文件 | txt, docx, doc, pdf, rtf, xlsx, xls, csv, pptx, ppt, md, odt |
| 3 | 视频文件 | mp4, avi, mkv, mov, wmv, flv, m4v |
| 4 | 音频文件 | mp3, wav, flac, aac, ogg, wma |
| 5 | 应用程序文件 | exe, lnk, sh, bat, cmd, msi, apk, app |
| 6 | 网页文件 | html, htm, css, js, xml, json, php, asp, jsp |
| 7 | 数据库文件 | sql, sqlite, db, mdb, accdb, pgd, pgdump, mongodb, rdb, db2 |
| 8 | 图片文件 | png, jpg, jpeg, webp, gif, bmp, tiff, tif, svg |
| 9 | 其他文件 | whl, z01-z10, 001-004, ttf, deb, tgz, vsix 等 |

要点：
- 上传 zip 包会自动归到"压缩文件"，pdf 归"文档文件"，无需手动选
- 特殊格式（whl/deb/vsix 等）会归到"其他文件"
- 前台筛选时"资源类别"即这些文件类型，方便按格式找

## 三、资源领域（按内容分类 = 专栏）

资源领域是资源板块的**内容专栏**（前台左侧第一个筛选组）。建议前期建 **5 个领域**：

| 序号 | 领域名称 | 领域简介（后台填写） | 放什么内容 |
|------|---------|---------------------|-----------|
| 1 | 行业标准 | 航天与开源相关标准、规范、协议文档 | CCSDS/ECSS 标准文档、GJB/GB-T 航天标准、接口协议规范 |
| 2 | 学习资料 | 教程、入门指南、论文、书籍、课程 | 开源项目入门教程、论文 PDF、awesome 精选列表、竞赛资料 |
| 3 | 安装包 | 软件安装包、固件、工具链 | SDS³ 各组件安装包（deb/whl）、星上固件、地面站工具 |
| 4 | 数据集 | 开源数据、遥测数据、TLE、遥感影像 | OPS-SAT 遥测数据集、PhiSat-2 数据规范、卫星 TLE 数据 |
| 5 | 技术报告 | 白皮书、设计文档、项目技术文档 | SDS³ 架构/设计文档、开源项目技术报告、调研报告 |

可选（有内容再开）：**软件与代码**（示例/脚本/模板工程）、**活动资料**（比赛赛题、会议 PPT）。

> 领域名称建议简短（2-6 字）；领域简介一两句话说明"放什么"，前台展示给用户参考。

## 四、资源列表（怎么上传资源）

### 4.1 上传流程

1. 进入"资源列表"→ 点击**新增**
2. 填写资源信息：资源名称、所属**资源领域**、资源简介
3. 上传文件（扩展名决定自动归入的**资源类别**）
4. 保存后前台"资源发布"页即展示，可按领域/类别筛选

### 4.2 字段填写规范

| 字段 | 说明 |
|------|------|
| 资源名称 | 简短明确：如"OPS-SAT 遥测异常检测数据集""SDS³ 星务软件安装包" |
| 所属领域 | 选第二节的领域（行业标准/学习资料/安装包/数据集/技术报告） |
| 资源简介 | 1-2 句：是什么 + 用途 + 来源/版本（见 4.3） |
| 资源类别 | 自动按扩展名归类，无需手动选 |
| 文件 | 一次一个或多个相关文件 |

### 4.3 简介写作模板

```
一句话说明内容：XX（资源名）是/提供/包含……（面向 XX 场景/用途）。
补充要点：版本/时间/来源/配套说明（1-2 句）。
```

示例：
- "CCSDS 空间数据系统咨询委员会标准合集（TM/TC、CFDP、SDLS），供星载通信开发参考。"
- "SDS³ 星脑 AI 处理机 BMC 固件安装包（MS2612 系列，STM32F105 平台），含烧录说明。"

## 六、维护规范

### 6.1 来源与版权

- 只上传**允许公开分发**的资源；外部资源注明来源与 License
- 标准/规范文档注意版权（优先放公开、官方免费分发的）
- 内部/涉密文档不上传

### 6.2 更新频率

- 首批上线：每个领域先放 2-3 个资源
- 常态：随项目发布、调研成果、标准更新持续补充（建议每月至少 1 批）
- 及时清理过期/失效资源（如版本过旧安装包）

### 6.3 与资讯/项目联动

- 上传重要资源时，在资讯"项目速递/技术前沿"发一条说明
- 新收录的开源项目，其配套文档/数据集同步传到对应领域
- 资源命名保持与项目名一致，便于检索

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 上传后类别不对 | 检查文件扩展名是否在系统类别映射内；特殊格式会归"其他文件" |
| 找不到想要的领域 | 在"资源领域"新增领域，再编辑该资源改归属 |
| 领域删不掉 | 该领域下还有资源，先清空或迁移 |
| 前台筛选看不到内容 | 检查资源是否已保存、领域/类别是否正确 |
| 大文件上传 | 压缩后上传；超大文件走平台限制或提供外部下载链接 |
