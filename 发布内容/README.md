## 四、使用说明

1. 每个子文件夹放对应分类的**待发布内容**（项目简介、资源文件、资讯草稿）
2. 内容准备好后，到后台对应板块发布（项目管理 / 资源管理 / 资讯管理）
3. 发布时选择与文件夹同名的分类，保持前后台口径一致
4. 新增分类时，先在后台建好，再在本目录同步新建同名子文件夹
5. 本目录与《开源项目调研.md》（调研/目录）配合使用，收录清单按分类归档
