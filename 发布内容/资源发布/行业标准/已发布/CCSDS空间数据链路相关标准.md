# CCSDS 空间数据链路相关标准

| # | 资源名称 | 资源简介 |
|---|---------|---------|
| 1 | **Space Packet Protocol（空间数据包协议）** | 规定 CCSDS 空间数据包的格式、协议和处理机制，为航天器与地面系统之间进行标准化数据交换提供基础协议，是 CCSDS 空间数据系统的重要基础标准。 |
| 2 | **TM Space Data Link Protocol（遥测空间数据链路协议）** | 规定遥测空间数据链路的协议、服务和处理过程，用于规范航天器向地面或其他航天器传输遥测数据的链路层机制，为航天器遥测数据的可靠传输提供标准化基础。 |
| 3 | **TC Space Data Link Protocol（遥控空间数据链路协议）** | 规定遥控空间数据链路的协议、服务和处理过程，用于规范地面或其他航天器向目标航天器发送遥控数据，为航天器遥控通信提供统一的数据链路规范。 |
| 4 | **AOS Space Data Link Protocol（先进在轨系统空间数据链路协议）** | 规定先进在轨系统（AOS）的空间数据链路协议和服务，适用于星地、地星以及星间数据传输，为高性能航天数据通信提供标准化的数据链路机制。 |
| 5 | **Unified Space Data Link Protocol（统一空间数据链路协议）** | 定义统一空间数据链路协议（USLP），用于不同类型空间链路的数据传输，为星地、星间等场景提供统一的数据链路框架，适用于现代航天器通信与空间数据系统。 |
| 6 | **Proximity-1 Space Link Protocol — Data Link Layer（Proximity-1 近距离空间链路协议——数据链路层）** | 规定 Proximity-1 空间链路协议的数据链路层机制，主要用于航天器之间的近距离通信，可应用于编队飞行、交会对接以及深空探测等任务。 |
| 7 | **Space Data Link Security Protocol（空间数据链路安全协议）** | 规定 CCSDS 空间数据链路的安全机制，为遥测、遥控及其他空间数据链路提供数据认证、完整性保护和机密性保护等安全能力。 |
| 8 | **CCSDS Cryptographic Algorithms（CCSDS 密码算法）** | 规定 CCSDS 空间数据系统推荐使用的密码算法，为航天器通信和空间数据链路提供密码学基础，可用于数据加密、认证和安全通信等场景。 |
| 9 | **Licklider Transmission Protocol (LTP) for CCSDS（CCSDS Licklider 传输协议）** | 面向具有长时延、链路间歇连接等特点的空间通信环境，规定 Licklider 传输协议在 CCSDS 空间通信体系中的应用，为深空通信和延迟/中断容忍网络提供可靠的数据传输机制。 |
| 10 | **Space Link Extension — Forward CLTU Service Specification（空间链路扩展——前向 CLTU 服务规范）** | 规定空间链路扩展（SLE）前向 CLTU 服务的功能和接口，用于规范地面系统向航天器传送连续链路传输单元（CLTU）的服务过程，可用于航天测控和地面站系统。 |
