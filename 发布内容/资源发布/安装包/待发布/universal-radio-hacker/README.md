## 资源简介

Universal Radio Hacker（URH）是开源无线协议信号分析与逆向工具，可对捕获的射频信号进行协议解码、比特流分析与自动调制识别，支持常见 SDR 硬件回放，常用于卫星遥测链路分析与通信协议研究。

- 版本：2.10.0（2026-08-11 核实）
- 下载：https://github.com/jopohl/urh/releases
- 许可证：GPL-3.0
- 适用环节：测控通信 / 信号分析与协议研究
