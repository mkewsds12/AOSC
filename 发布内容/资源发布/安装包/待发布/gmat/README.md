## 资源简介

GMAT（General Mission Analysis Tool）是 NASA 开源的航天任务分析软件，支持轨道设计、轨道机动、姿态与导航仿真、可见性与覆盖分析等，功能对标商业 STK，是卫星任务方案设计与轨道分析的首选开源工具。

- 版本：R2026a（2026-08-11 核实，Windows 包实际 385MB）
- 下载：https://sourceforge.net/projects/gmat/（官方：https://gmat.sourceforge.net/）
- 许可证：NASA-1.3（NOSA）
- 适用环节：任务分析 / 轨道设计与仿真（含姿控仿真）
