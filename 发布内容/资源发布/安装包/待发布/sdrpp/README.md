## 资源简介

SDR++ 是轻量跨平台软件无线电接收软件，界面简洁，支持 RTL-SDR、Airspy、SDRplay、HackRF 等多种 SDR 硬件，提供频谱、瀑布图、AM/FM/SSB 等解调，适合卫星信号快速观测与测控链路验证。

- 版本：nightly（2026-08-11，官方仓库 AlexandreRouma/SDRPlusPlus）
- 下载：https://github.com/AlexandreRouma/SDRPlusPlus/releases
- 许可证：GPL-3.0
- 适用环节：测控通信 / 信号接收观测
