## 资源简介

Gqrx 是跨平台开源软件无线电（SDR）接收机，配合 RTL-SDR、Airspy、HackRF 等常见 SDR 硬件，实现频谱显示、AM/FM/SSB 解调、广播与卫星信号监听，是测控通信信号观测与无线电爱好者的常用工具。

- 版本：2.17.7（2026-08-11 核实）
- 下载：https://github.com/gqrx-sdr/gqrx/releases
- 许可证：GPL-3.0
- 适用环节：测控通信 / 信号接收观测
