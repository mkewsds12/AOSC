## 资源简介

SatDump 是开源卫星数据下行解调与解码工具，支持 NOAA、Meteor、GOES、风云等系列气象与对地观测卫星信号的实时/离线解调、解码与图像合成，带图形界面与命令行两种用法，适合地面站运维与卫星下行数据处理。

- 版本：1.2.2（2026-08-11 核实）
- 下载：https://github.com/SatDump/SatDump/releases
- 许可证：GPL-3.0
- 适用环节：卫星运维 / 下行数据解调
