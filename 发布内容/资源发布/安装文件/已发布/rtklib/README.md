## 资源简介

RTKLIB 是开源 GNSS 定位处理工具包，支持 GPS/北斗/Galileo/GLONASS 等多系统的实时与后处理定位，包含 RTK、PPP、精密单点定位等高精度解算，带图形界面（RTKLIB Demo5），可用于地面站时间同步、导航载荷数据处理与星地链路验证。

- 版本：2.5.1（2026-08-11 核实）
- 下载：https://github.com/rtklibexplorer/RTKLIB/releases
- 许可证：BSD-2-Clause
- 适用环节：导航应用 / GNSS 数据处理
