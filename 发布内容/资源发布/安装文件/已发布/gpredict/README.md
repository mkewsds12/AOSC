## 资源简介

Gpredict 是开源实时卫星轨道预测与跟踪软件，支持多星同时跟踪、TLE 星历管理、过境预报、多普勒频移计算与天线指向控制，是卫星地面站运维、业余无线电与测控任务规划的基础工具。

- 版本：2.3.37（2026-08-11 核实 Windows 版）
- 下载：https://sourceforge.net/projects/gpredict/（源码见 https://github.com/csete/gpredict）
- 许可证：GPL-2.0
- 适用环节：卫星运维 / 轨道预测跟踪
