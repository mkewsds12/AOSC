## 资源简介

WhiteboxTools 是开源地理空间分析工具集，提供 500+ 个栅格/矢量处理与地理分析命令，涵盖地形分析、水文、LiDAR 与遥感影像处理，可独立命令行运行，也可配合 QGIS 等 GIS 软件使用，适合遥感影像与地理数据处理应用。

- 版本：Next Gen（2026-08-11 核实，官方仓库 jblindsay/whitebox_next_gen，无独立 release 二进制）
- 下载：https://www.whiteboxgeo.com/（Python：pip install whitebox；或 R / QGIS 插件）
- 许可证：核心引擎开源（具体条款发布前核实）
- 适用环节：遥感应用 / 地理空间数据处理
