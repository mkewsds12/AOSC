# 知识科普 · 资讯模板

> 栏目：知识科普（后台：资讯管理 → 资讯列表 → 新增）
> 用途：面向社区成员的航天与开源知识科普
> 填写后发到后台，栏目选"知识科普"

## 基本信息

- 标题（必填）：一句话说明科普主题，如"卫星为什么能在太空不掉下来？"
- 概览（必填）：1 句摘要，列表页展示
- 标签（1-3 个）：如 轨道原理 / 星座组网 / 星上软件 / 开源许可证
- 作者：发布账号名
- 状态：草稿 → 已发布
- 首页推荐：重点科普可勾选

## 首图（建议）

16:9 配图（示意图/原理图/渲染图），优先原创或开源素材，注意版权。

## 正文（建议 300-600 字）

第一段：从问题/现象切入，引起兴趣。
第二段：讲清原理（分点/小标题，通俗语言）。
第三段：联系航天开源生态或社区相关内容，引导关注。

参考选题：
- 卫星姿态怎么控制？——从反作用轮到星敏感器
- 什么是软件定义卫星？
- 立方星为什么这么流行？
- 开源许可证怎么选（MIT / Apache / GPL）？
- 低轨星座是怎么组网的？
