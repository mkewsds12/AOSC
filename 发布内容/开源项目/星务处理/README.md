# 星务处理（发布内容目录）

本文件夹用于归档「开源项目 → 星务处理」分类的待发布内容。

## SDS³ 自有项目

- [sds3_semx](https://www.gitlink.org.cn/sds3/sds3_semx) — 面向 Xilinx 7 系列 SRAM 型 FPGA 的单粒子翻转（SEU）缓解：配置存储器周期校验 + 局部热修复，含 SEU 注入验证。
- [sds3_bmc_firmware](https://www.gitlink.org.cn/sds3/sds3_bmc_firmware) — 星脑 AI 处理机（MS2612 系列）BMC 控制器固件（STM32F105RC）：电源管理、星务通信、模式管理、状态监测、故障恢复、GPU 刷机与在线升级。
- [sds3_autodeploy](https://www.gitlink.org.cn/sds3/sds3_autodeploy) — 基于 .deb 包投递的在轨软件自动部署工具。
- [sds3_firmware](https://www.gitlink.org.cn/sds3/sds3_firmware) — 星载 BMC / MCU 固件升级与管理工具。
