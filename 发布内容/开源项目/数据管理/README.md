# 数据管理（发布内容目录）

本文件夹用于归档「开源项目 → 数据管理」分类的待发布内容。

## SDS³ 自有项目

- [SDS3_UploadFileManager](https://www.gitlink.org.cn/sds3/SDS3_UploadFileManager) — 星脑单机 GPU 系统上注文件管理：还原后的上注文件部署、日志管理。
- [SDS3_BuildDownloadFile](https://www.gitlink.org.cn/sds3/SDS3_BuildDownloadFile) — 星脑单机 GPU 系统数传数据管理：生成数传数据、清理缓存、遥测与日志管理。
- [SDS3_ReBuildUploadFile](https://www.gitlink.org.cn/sds3/SDS3_ReBuildUploadFile) — 星脑单机 GPU 操作系统上注数据还原：按协议还原上注文件、状态/临时数据/日志管理。
