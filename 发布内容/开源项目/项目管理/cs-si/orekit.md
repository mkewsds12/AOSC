## 项目简介

Orekit 是 Java 编写的空间飞行动力学核心库，提供高精度轨道传播、轨道确定、姿态计算、机动与事件检测等能力，被众多航天机构与商业软件采用，是轨道仿真领域事实上的标准库之一。
