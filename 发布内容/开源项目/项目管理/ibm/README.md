# IBM · GitLink 社区镜像组织

> 来源：https://github.com/IBM
> 定位：在 GitLink 建立该 owner 的国内社区镜像组织/账号，镜像其开源仓库
> 状态：待执行

## 一、新建组织填写指南（GitLink → 新建组织）

| 表单项 | 填写内容 |
|--------|---------|
| 组织账号 | `ibm`（被占用则 `ibm-mirror`） |
| 组织名称 | `IBM（社区镜像）` |
| 组织描述 | 非官方社区镜像，仅收录 IBM 公开发布的航天相关开源项目；版权归原作者（https://github.com/IBM）；仓库以只读镜像方式同步，每 8 小时更新一次 |
| 所在地区 | 可留空或按项目背景填写 |
| 选择头像 | 上传本文件夹 avatar.png |
| 权限 | 默认不勾 |

## 二、仓库镜像清单

| 仓库/项目 | 项目 md | 许可证 | 镜像可行性 |
|-----------|---------|--------|-----------|
| IBM/spacetech-kubesat（KubeSat） | spacetech-kubesat.md | Apache-2.0 | ✅ 可镜像 |

## 三、操作流程

1. 建组织 → 2. 组织内逐个「导入项目」（表单见各项目 md，注意把「拥有者」改选为本组织）→ 3. 核对 README/LICENSE 同步 → 4. 专区后台按项目 md 标注的分类上架

## 四、合规与备注

- 非官方社区镜像，不冒充官方/作者本人，保留 LICENSE 与版权声明
- 无 LICENSE 只收链接不镜像
- IBM 为大型商业公司官方组织，社区镜像尤其要注意不冒充官方：组织名称与描述必须明确「非官方社区镜像」字样；仅镜像其航天相关的 spacetech-kubesat 仓库，不做全量镜像
