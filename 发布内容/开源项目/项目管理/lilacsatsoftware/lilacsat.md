## 项目简介

紫丁香星务软件是哈尔滨工业大学紫丁香学生微纳卫星团队在 Gitee 上的星务软件开源组织主页，集中发布团队在轨微纳卫星的星务/星载软件项目，是国内高校航天开源的重要窗口。镜像收录自 https://gitee.com/lilacsatsoftware，License 以各源仓库 LICENSE 为准。

## GitLink 导入填写指南（镜像方式）

| 表单项 | 填写内容 |
|--------|---------|
| 导入仓库URL | 该来源为组织主页，无法整体镜像，需逐个导入组织下的星务软件仓库（仓库清单见下方说明） |
| 导入私有项目 | 不勾选（源仓库为公开项目） |
| 拥有者 | `sds3`（下拉里没有则需先加入组织） |
| 项目名称 | 按各仓库实际名称命名 |
| 项目标识 | 各仓库英文标识（以源仓库为准） |
| 项目简介 | 按各仓库说明填写，末尾含「镜像收录自 https://gitee.com/lilacsatsoftware，License 以源仓库 LICENSE 为准」 |
| 将项目设为私有 | 不勾选 |
| 该仓库将是一个镜像 | **勾选**（仓库只读，每 8 小时自动与源站同步） |
| 项目类别 | 星务处理 |
| 项目语言 | 以源仓库为准 |

## 重点仓库清单

该组织主页下的具体仓库名称与数量需以 https://gitee.com/lilacsatsoftware 页面实际为准，收录时请逐仓库核对后按「组织地址/仓库名」拼出 URL 导入（如已收录 ASRTU-1 星务软件，注意避免重复）。

## 导入后上架专区

1. 导入完成后核对 README / LICENSE 是否同步正常
2. 专区管理后台 → 项目管理 → 项目列表 → 添加项目 → 搜索本项目 → 分类选「星务处理」→ 保存
