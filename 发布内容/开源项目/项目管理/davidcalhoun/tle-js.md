## 项目简介

tle.js 是 JavaScript 的 TLE 解析与 SGP4 传播轻量实现，可在浏览器与 Node.js 中直接完成卫星位置计算，适合 Web 端卫星可视化应用（Go 语言同类实现可参考 go-satellite）。
