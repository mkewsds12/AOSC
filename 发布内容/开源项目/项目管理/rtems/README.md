## 一、新建组织填写指南（GitLink → 新建组织）

| 表单项 | 填写内容 |
|--------|---------|
| 组织账号 | `rtems`（被占用则 `rtems-mirror`） |
| 组织名称 | `rtems（社区镜像）` |
| 组织描述 | 非官方社区镜像，仅收录 rtems 公开发布的开源项目；版权归原作者（https://gitlab.rtems.org/rtems）；仓库以只读镜像方式同步，每 8 小时更新一次 |
| 所在地区 | 可留空或按项目背景填写 |
| 选择头像 | 头像需手动从来源页获取（自建 GitLab，无法自动下载） |
| 权限 | 默认不勾 |

## 三、操作流程

1. 建组织 → 2. 组织内逐个「导入项目」（表单见各项目 md，注意把「拥有者」改选为本组织）→ 3. 核对 README/LICENSE 同步 → 4. 专区后台按项目 md 标注的分类上架

## 四、合规与备注

- 非官方社区镜像，不冒充官方/作者本人，保留 LICENSE 与版权声明
- 无 LICENSE 只收链接不镜像
- 平台特殊性：来源为 RTEMS 项目自建 GitLab（gitlab.rtems.org），非 GitHub；2026-08-10 探测时该站点触发反爬限流（HTTP 429），许可证未能自动确认，导入前需人工访问源仓库页面确认 LICENSE 条款
- GitLink 导入自建 GitLab 仓库时需确认平台支持自定义 Git 源地址
