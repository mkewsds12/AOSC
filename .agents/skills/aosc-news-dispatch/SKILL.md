# 新闻动态推文生成

本 skill 用于为 AOSC「新闻动态」栏目整理行业新闻推文，覆盖**卫星、火箭、商业航天下游产业**（遥感/通信/导航应用、开源生态、政策标准等），风格与已发布新闻动态及《新闻来源清单.md》一致。

## 一、任务定位

用户要求"看看有哪些行业新闻 / 整理成推文"时，你需要：

1. **联网搜集**近期（默认 1 周内）国内外航天/商业航天行业新闻——用 agent-reach skill 的搜索能力（`mcporter call 'exa.web_search_exa(query: "...", numResults: 5)'`；后端不可用时用 fetch_webpage 抓权威站点），优先《新闻来源清单.md》中的来源（新华社/央视/国家航天局/航天科技集团/SpaceNews/NASA/ESA 等）。
2. **筛选**：只保留卫星、火箭、下游产业相关且有发布价值的新闻（重大发射/回收、商业航天融资与组网、卫星应用落地、航天开源生态、政策标准）。
3. **逐条整理成推文**：格式固定为「一段话 + 一个图 + 来源」。
4. 产出保存到 `发布内容/新闻资讯/新闻动态/待发布/`。

## 二、新闻范围与选题

| 方向 | 示例 |
|------|------|
| 火箭/发射 | 重大发射、可回收、海上发射、民营火箭 |
| 卫星 | 组网星座、在轨运行、卫星研制 |
| 下游产业 | 遥感/通信/导航应用、星载 AI、商业航天公司动态 |
| 开源生态 | NASA/ESA 开源工具、开源卫星项目、星载 OS 在轨 |
| 政策标准 | 航天法、商业航天政策 |

时间规则：**只发 1 周内新闻**（栏目硬性要求）；用户指定更早时间线时说明后按需处理。

## 三、推文格式（每篇严格遵循）

```markdown
## 新闻N：<标题>

- 标题：<时间+主体+事件三要素的精简标题>
- 概览：一句话概括 + 注明来源媒体
- 首图：

![<图片说明>](图片/xxx.jpg)

- 正文：一段话（80-150 字）交代事件（谁、何时、做了什么）+ 补充 1-2 句要点/数据/意义 + 注明来源与原文链接。
```

### 格式要点

- **一段话**：80-150 字，先事件、再要点、后意义；不原样转载，只摘要转述
- **一个图**：每条配 1 张图（首图），占位写 `![说明](图片/文件名.jpg)`，并在文件头部说明图片目录与来源建议；无法获取图片时保留占位并注明"待放图"
- **来源**：必填——媒体名 + 原文链接 `[原文链接](URL)`
- 标签（可选）：商业航天 / 可回收火箭 / 发射任务 / 卫星应用 / 组网星座 / 航天政策 / 开源生态

## 四、工作流程

1. 确认时间窗口（默认近 1 周）与范围（默认卫星/火箭/下游产业全覆盖）
2. 联网搜集：用 agent-reach（或 fetch_webpage 兜底）搜权威来源，至少覆盖 3-5 条可发布新闻
3. 筛选去重：剔除已发布过的内容（比对 `新闻动态/已发布/`），保留有发布价值的
4. 逐条整理成推文（按第三节模板）
5. 保存到 `新闻动态/待发布/`：
   - 多条新闻 → 合集文件 `YYYY-MM-新闻动态速递-国内篇.md`（或按需国际篇），参考现有速递文件结构
   - 单条 → 独立文件 `YYYY-MM-<事件>推文.md`
6. 汇报：给出文件路径、新闻条数、每条主题与来源简述

## 五、示例

**用户**：帮我看看目前有哪些行业相关新闻，整理成推文
**输出**：`2026-08-新闻动态速递-国内篇.md`，内含若干条：
- 新闻一：标题「我国成功发射卫星互联网低轨 XX 组卫星」+ 首图占位 + 一段话正文（事件/要点/意义）+（来源：新华社，[原文链接](URL)）
- 新闻二：民营商业火箭远海发射……（同上格式）

## 六、边界情况

- 用户直接给出新闻/链接：跳过搜集，直接按格式整理
- 无近期可发布新闻：如实说明，不硬凑；可建议补充"开源生态"类题材
- 联网不可用：用已知可靠信息整理并标注"数据未经核实/待核实"
- 用户指定范围（只要火箭 / 只要卫星应用）：按指定范围筛选
- 用户要求单篇独立推文 vs 合集：按用户要求落盘
