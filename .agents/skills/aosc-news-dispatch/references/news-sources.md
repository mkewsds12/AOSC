# 新闻动态 · 一线新闻来源清单

> 用途：从以下权威来源筛选 1 周内的航天/商业航天/开源动态，摘要转述后发布到「新闻动态」栏目
> 规则：只做摘要转述，注明来源媒体 + 原文链接；不原样大段转载

## 三、选题建议

- 重大发射/回收成功（如长征十号乙首飞、可回收火箭）
- 商业航天公司融资、组网、出海动态
- 卫星应用（遥感/通信/导航）落地新闻
- 航天开源生态动态（NASA cFS、ESA 开源工具、开源卫星项目）
- 政策与标准（航天法、商业航天政策）

## 四、发布时字段参考

- 标签（1-3 个）：商业航天 / 可回收火箭 / 发射任务 / 卫星应用 / 组网星座 / 航天政策 / 开源生态 等
- 来源：如"国家航天局官网 / 新华社"
- 原文链接：必填，附原文 URL
