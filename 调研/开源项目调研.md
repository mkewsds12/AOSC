# 开源项目调研

> 调研时间：2026-08-10
> 调研方式：agent-reach（GitHub Topics / GitLab / Gitee）+ 多路并行检索
> 用途：为 SDS³ 卫星开源社区（gitlink.org.cn/sds3）收录项目提供清单
> 领域分类对应《SDS3_GitLink_组织管理与仓库调研.md》中的 14 类划分（sds3-ref-/os-/virt-/cdh-/dm-/ttc-/adcs-/plan-/alg-/app-/gse-/sim-/doc-/meta-）

## 调研说明

- 覆盖范围：小卫星、立方星、PocketQube、智能星、智能星座、星上计算、星上 AI/智能体、测运控、地面站
- 平台：GitHub、GitLab、Gitee、SourceForge、Bitbucket 等
- 收录原则：宁多勿漏，优先标注[核心]；可直接对应到组织仓库分类
- 已知整星项目的子模块（OBC/EPS/ADCS/COMMS）通常拆出来归入对应领域类

### 17.6 本轮重点结论

1. **必须补录**：PyCubed（开源 OBC 硬件标杆）、DelfiSpace（最完整高校开源整星组织 63 仓库）、JAXA open-set（星上边缘 AI 官方）、cFS 工具全家桶（CTF/CCDD/官方地面系统）
2. **深空网络主线**：ION-DTN（NASA JPL）+ CFDP 各语言实现（cfdp-py / EmbeddedCFDP / NASA CF）+ Yamcs，可组成"深空通信"专题
3. **嵌入式 CCSDS 宝藏**：OpenSpaceCode 系列是嵌入式微型化 CCSDS 的最佳参考，与 SDS³ 星载轻量化诉求高度契合
4. **国产缺口**：国内高校卫星开源除紫丁香外仍少，建议社区主动推动国产立方星（KS-1Q 等）拆解收录
5. **硬件方向**：PyCubed + DelfiSpace 的 PCB/KiCad 设计 + Modular-CubeSat-Structure 的 3D 结构，构成"开源硬件"子专题，适合与软件栈配合宣传
